01端到端运行生命周期

02Agent 状态机主路径

运行时由显式状态机驱动；每个状态迁移落库/落轨迹，含原因、重试次数与关联截图。

stateDiagram-v2
  [*] --> CREATED
  CREATED --> CONNECTING
  CONNECTING --> PREPARING: 会话就绪
  CONNECTING --> FAILED: 建连失败
  PREPARING --> OBSERVING: 前置完成
  PREPARING --> RECOVERING: 准备失败

  OBSERVING --> UNDERSTANDING
  UNDERSTANDING --> RETRIEVING_MEMORY
  RETRIEVING_MEMORY --> PLANNING

  PLANNING --> OBSERVING: 需要更多观察
  PLANNING --> VERIFYING: 任务已完成
  PLANNING --> RESOLVING_ACTION

  RESOLVING_ACTION --> EXECUTING: 快捷键/回放
  RESOLVING_ACTION --> GROUNDING: 需视觉定位
  RESOLVING_ACTION --> FAILED: 不安全/拒止

  GROUNDING --> EXECUTING: 有可信候选
  GROUNDING --> RECOVERING: 无候选

  EXECUTING --> WAITING
  EXECUTING --> RECOVERING: 发送异常
  WAITING --> VERIFYING
  WAITING --> RECOVERING: 等待超时

  VERIFYING --> RECORDING: 步骤通过
  VERIFYING --> RECOVERING: 可恢复失败
  VERIFYING --> FAILED: 不可恢复

  RECOVERING --> OBSERVING: 恢复后重试
  RECOVERING --> FAILED: 额度耗尽

  RECORDING --> STEP_COMPLETED
  STEP_COMPLETED --> OBSERVING: 有下一步
  STEP_COMPLETED --> PASSED: 无下一步
  PASSED --> [*]
  FAILED --> [*]
  CANCELLED --> [*]

关键状态 CANCELLED 可由外部取消令牌切入多数活动态。 模型不得自行无限重试或宣布测试最终通过——这些权限属于状态机与 Verifier。

04双轨结果：效果 vs 业务验证

Feature 002 强制拆开两路结果，报告与判定不得合并成单一 pass/fail。

ActionEffect UI 是否响应

  • no_effect — 像素/OCR/模板几乎无变
  • expected_effect — 变化符合动作预期区域
  • unexpected_effect — 变化远离目标（可触发 022）
  • effect_uncertain — 证据不足

由本地感知与 classify_action_effect 产出。

StepVerificationResult 业务是否达标

  • passed / failed / uncertain
  • 条件：text_appears、template_*、visual_question、screen_changed…
  • verification_mode: business 要求真实断言
  • effect_only 可仅凭效果通过，报告会标注

由 business_resolver 独立裁决；011 防止弱 OCR 否决高置信视觉结论。

06失败分类与恢复

Recovery Engine 按 FailureType 选策略；每策略有次数、冷却、是否耗全局额度与是否需强模型/人工。

VNC_*有限重连 → 重新观察会话层
PAGE_NOT_STABLE延长等待 · 缩小 ROIWait Engine

07探索模式 vs 回放模式

新用例走探索（模型调用多、沉淀轨迹）；回归走回放（happy path 近零模型调用，失败才升级）。

探索 explicit / goal_driven

  • 观察 → 检索经验 → Planner → Policy → Ground → 执行 → 验证
  • 保存完整截图与模型响应
  • 自动产生候选回放轨迹（016）
  • 适合编写与硬化用例

回放 --mode replay

  • 页面指纹 → 模板/OCR 锚点 → 执行 → 验证
  • happy path：Planner/Grounder 双零
  • 失败：MiMo 重定位 → 验证 → 候选补丁待审
  • 补丁不得自动覆盖正式基线
