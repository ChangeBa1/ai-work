OPOS（OLE for Retail POS）是一个零售外设的标准接口规范。它的 ResultCode 是标准定义的。

OPOS ResultCode 常量： - OPOS_SUCCESS = 0 - OPOS_E_CLOSED = 101 - OPOS_E_CLAIMED = 102 - OPOS_E_NOTCLAIMED = 103 - OPOS_E_NOSERVICE = 104 - OPOS_E_ILLEGAL = 105 (Illegal) - OPOS_E_NOHARDWARE = 106 - OPOS_E_OFFLINE = 107 - OPOS_E_NOEXIST = 108 - OPOS_E_EXISTS = 109 - OPOS_E_FAILURE = 110 - OPOS_E_TIMEOUT = 111 - OPOS_E_BUSY = 112 - OPOS_E_EXTENDED = 113

所以 112 = OPOS_E_BUSY（设备忙）。

OPOS_E_BUSY 的官方定义（来自 UnifiedPOS / OPOS 标准）： "The device cannot be opened/claimed/enabled, because it is already owned/claimed/enabled by another application. Or, the device is busy and cannot perform the requested action."

具体来说，OPOS_E_BUSY 在不同方法上的含义： - Open 时：设备已被另一个应用打开（独占型 SO），或者设备忙。 - Claim 时：设备已被另一个应用 Claim（独占占用），或者设备忙无法被独占。 - 其他操作时：设备正在执行其他操作，忙。

对于釣銭機 Claim 返回 112 的具体情况： - 设备被另一个应用/进程 Claim 了 - 或者设备硬件忙（正在进行某个操作，如出钞、清点）
