BO 模块的环境配置定义文件，包含数据库连接字符串、存储连接字符串、服务 URL、文件下载路径等环境相关的配置项。这是 BO 运行时的关键配置入口。

3. 关键逻辑 walkthrough

数据库配置（第4-7行）：

定义了两个数据库实例：POS4U_Trial_Master（主数据库，含企业和店铺相关信息）和 POS4U_Trial_Tran（交易数据库，含交易流水）。分别提供只读和读写连接串，推测是读写分离架构的配置。

存储配置（第13-16行）：

使用 UseDevelopmentStorage=true 表示在本地开发测试环境中使用 Azure Storage Emulator（C:\Program Files (x86)\Microsoft SDKs\Azure\Storage Emulator\），生产环境会替换为真实的 Azure 存储连接串。

后台服务 URL（第11-12行）：

BO 通过 WCF 调用后台服务的任务队列接口，URL 指向 localhost:63526 的 BackgroundService.svc。

ConnectionName（第21行）：

ConnectionName=Local 表明这是本地开发环境配置。项目维护了多套环境配置（Venus/Mercury/Test/Dev/Local），通过切换此配置选择目标环境。

  • 被 BO 框架在运行时加载
  • 依赖 SQL Server LocalDB 或 SQL Server Express（.SQLEXPRESS 实例名）
  • 依赖 Azure Storage Emulator 或真实 Azure 存储账户
  • 依赖后台服务（BackgroundService.svc 在 localhost:63526）

6. 错误处理与边界情况

  • 数据库连接串使用了 Windows 集成认证（Integrated Security=True），意味着运行 BO 的应用程序池账户必须有数据库访问权限。
  • 文件下载路径（第17-19行）需要确保 C:\POS4U\Work\ 目录存在且可写。

文件：Source/Device/Device.CAFISArch/CAFISArchOtherError.xml

1. 文件定位

CAFIS Arch 卡支付终端的"其他错误"集合定义文件，包含大量具体的错误代码及其错误信息、原因和处理指导。这是 CAFIS Arch 设备驱动错误处理的核心数据源之一。

2. 对外暴露内容

通用错误定义（<Error> 元素，第3-27行）

错误代码 行号 错误信息
TFWL0001 第4行 业务开始不可 - 不支持的业务
TFWL0002 第8行 中止 - 交易已中止
TFWL0003 第12行 联动数据检查错误 - 输入信息不正确
TFWL0004 第16行 其他异常结束 - 意外错误
TFWC0001 第20行 篡改检测 - 检测到非法行为
TFWC0002 第24行 电池电量检查错误 - 电量不足

3. 关键逻辑 walkthrough

CAFIS Arch 驱动在运行时检测到卡终端错误时，会先匹配通用错误码（<Error> 元素），如果匹配失败则进一步匹配详细错误码（<ErrorDetail1> 元素）。匹配成功后，提取 ErrorMessage、ErrorCause、ErrorHandling 用于用户提示和日志记录。
