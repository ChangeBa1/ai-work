# Claude Code + DeepSeek API: Complete Usage Guide

## 1. Environment Variables

All configuration is done via environment variables—no config files are used.

### Required Variables

| Variable | Value | Purpose |
|---|---|---|
| `ANTHROPIC_BASE_URL` | `https://api.deepseek.com/anthropic` | API endpoint for DeepSeek's Anthropic-compatible interface |
| `ANTHROPIC_AUTH_TOKEN` | Your DeepSeek API Key | Authentication token obtained from the DeepSeek Platform |

### Model Selection Variables

| Variable | Value | Purpose |
|---|---|---|
| `ANTHROPIC_MODEL` | `deepseek-v4-pro[1m]` | Primary model used by Claude Code |
| `ANTHROPIC_DEFAULT_OPUS_MODEL` | `deepseek-v4-pro[1m]` | Maps to the "opus-tier" model |
| `ANTHROPIC_DEFAULT_SONNET_MODEL` | `deepseek-v4-pro[1m]` | Maps to the "sonnet-tier" model |
| `ANTHROPIC_DEFAULT_HAIKU_MODEL` | `deepseek-v4-flash` | Maps to the "haiku-tier" model (faster/cheaper) |

### Subagent & Effort Variables

| Variable | Value | Purpose |
|---|---|---|
| `CLAUDE_CODE_SUBAGENT_MODEL` | `deepseek-v4-flash` | Model used for sub-agent tasks (background subtasks) |
| `CLAUDE_CODE_EFFORT_LEVEL` | `max` | Controls the reasoning/effort budget |

## 2. Configuration Method

**There is no config file.** All settings are passed as environment variables at runtime.

### Linux / macOS (terminal)

```bash
export ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
export ANTHROPIC_AUTH_TOKEN=<你的 DeepSeek API Key>
export ANTHROPIC_MODEL=deepseek-v4-pro[1m]
export ANTHROPIC_DEFAULT_OPUS_MODEL=deepseek-v4-pro[1m]
export ANTHROPIC_DEFAULT_SONNET_MODEL=deepseek-v4-pro[1m]
export ANTHROPIC_DEFAULT_HAIKU_MODEL=deepseek-v4-flash
export CLAUDE_CODE_SUBAGENT_MODEL=deepseek-v4-flash
export CLAUDE_CODE_EFFORT_LEVEL=max
```

### Windows (Powershell)

```powershell
$env:ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"
$env:ANTHROPIC_AUTH_TOKEN="<你的 DeepSeek API Key>"
$env:ANTHROPIC_MODEL="deepseek-v4-pro[1m]"
$env:ANTHROPIC_DEFAULT_OPUS_MODEL="deepseek-v4-pro[1m]"
$env:ANTHROPIC_DEFAULT_SONNET_MODEL="deepseek-v4-pro[1m]"
$env:ANTHROPIC_DEFAULT_HAIKU_MODEL="deepseek-v4-flash"
$env:CLAUDE_CODE_SUBAGENT_MODEL="deepseek-v4-flash"
$env:CLAUDE_CODE_EFFORT_LEVEL="max"
```

## 3. All Configuration Options Explained

- **`ANTHROPIC_BASE_URL`** — Must point to DeepSeek's Anthropic-compatible API endpoint. This redirects Claude Code's API calls from Anthropic's servers to DeepSeek's.
- **`ANTHROPIC_AUTH_TOKEN`** — Your DeepSeek API key; acts as the credential for authentication.
- **`ANTHROPIC_MODEL`** — The main model identifier. The value `deepseek-v4-pro[1m]` specifies the DeepSeek V4 Pro model with a 1-million-token context window (indicated by `[1m]`).
- **`ANTHROPIC_DEFAULT_OPUS_MODEL` / `_SONNET_MODEL` / `_HAIKU_MODEL`** — These override Claude Code's tier-based model selection. All three opus/sonnet tiers map to `deepseek-v4-pro[1m]`, while the haiku tier maps to `deepseek-v4-flash` (a faster, likely less expensive model).
- **`CLAUDE_CODE_SUBAGENT_MODEL`** — Controls which model handles background sub-agent tasks (e.g., parallel file searches, smaller subtasks). Set to `deepseek-v4-flash` for speed.
- **`CLAUDE_CODE_EFFORT_LEVEL`** — Set to `max` for the highest reasoning effort. This likely affects how many reasoning tokens the model uses.

## 4. Setup Steps (Fresh Install)

1. Install **Node.js 18+** and (for Windows) **Git for Windows**.
2. Install Claude Code globally: `npm install -g @anthropic-ai/claude-code`
3. Verify: `claude --version`
4. Set environment variables as shown above.
5. Navigate to your project: `cd /path/to/my-project`
6. Run `claude` to start the session.

## 5. Model Mapping (Important)

When using Claude Code or Claude Desktop APP, DeepSeek performs automatic model name mapping:

- Model names starting with **`claude-opus`** → mapped to **`deepseek-v4-pro`**
- Model names starting with **`claude-haiku`** or **`claude-sonnet`** → mapped to **`deepseek-v4-flash`**

This allows newer Claude Desktop APP developer mode "to bypass the APP's model name restrictions" by only changing `base_url` and `api_key`.

## 6. Web Search Feature

DeepSeek API "natively supports the Web Search function in Claude Code." When triggered, the model calls the Web Search tool, which generates **additional API requests** to summarize search results, incurring extra token costs. No configuration is needed to enable it—it activates automatically when the model deems a search necessary.

## 7. Key Notes & Limitations

- **No persistent config file** — Variables must be set every session or added to your shell profile (`.bashrc`, `.zshrc`, etc.).
- **API Key source** — Get your key from the DeepSeek Platform at `platform.deepseek.com/api_keys`.
- **Extra costs** — Web Search usage generates additional token-based charges beyond standard API calls.
- **The `[1m]` suffix** in model names (`deepseek-v4-pro[1m]`) indicates a 1-million-token context window capability.
- **Migration path** — If you already have Claude Code installed, you only need to set the environment variables (no reinstallation required).
