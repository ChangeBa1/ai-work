# 3.1フロントエンド処理方法

**フロントエンド処理方法**<span style="color: rgb(23,43,77);">は、ウェブアプリケーションやシステムにおけるユーザーインターフェース（UI）の操作やデータ表示に関する技術や手法を指します</span>

■ 処理方式概要 \
フォロン(VUE)とバックエンド(API)分離方式を採用する \
\
■ 路由规则 \
语义化的树结构 \
例子： \
const routes = \[ \
{ \
path: '/', \
name: 'Pages', \
redirect: '/dashboard', // 重定向到仪表盘页面 \
component: Layout, // 使用Layout作为布局组件 \
children: \[ \
{ \
path: 'budget', \
children: \[...budget\] // 将预算计划页面组件作为budget的子页面 \
} \
\] \
}\] \
\
export default \[ \
{ \
path: 'list', \
name: 'BudgetList', \
meta: { \
title: '修繕予算案', \
menu: true \
}, \
component: () =\> import('@/views/pages/budget/list/index.vue') \
}, \
{ \
path: 'detail', \
name: 'BudgetDetail', \
meta: { \
title: '修繕予算案', // setting page title \
menuKey: 'BudgetList' \
}, \
component: () =\> import('@/views/pages/budget/detail/index.vue') // lazily load Home component \
} \
\];
