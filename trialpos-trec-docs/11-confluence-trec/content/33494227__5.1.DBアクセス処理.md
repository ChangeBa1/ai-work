# 5.1.DBアクセス処理

DBアクセス処理 \
\
コネクションプーリングにてDBに接続する。 \
※データベースにコネクション（接続）する場合に、要求されるたびにコネクションを作成するのではなく、コネクションをプール（保持）して再利用する
