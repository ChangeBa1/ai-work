# 8.1.Gitフロー

![image2024-1-27_14-7-56.png](../attachments/33494234/image2024-1-27_14-7-56.png)

### 流程：

#### **1. 正常功能开发（Feature → Develop）**

- 在 Feature 分支开发新功能。

- 开发自测通过后，创建 Pull Request (PR) 并进行 <span style="color: rgb(255,0,0);">内部代码审查</span>。

- 审查通过后，合并到 Develop 分支,进行单体测试以及bug修复。

#### **2. 最终测试（结合・回归・性能测试）（Develop → Release）**

- Develop → Release 单体测试通过后 创建 PR，并进行<span style="color: rgb(255,0,0);">公司级代码审查</span>，提前发现技术是否有明显缺陷

- 在 release 分支进行最终测试

（技术审核放在最终测试阶段，如果技术审核放到最后，一旦却下，对上线有风险所以放在最终测试阶段）

#### **3. 发布（Release → Master）**

- **测试以及代码审查通过后，合并 Release 分支到 Master 分支，确保 Master 分支始终保持稳定的最新代码。**

### **<span style="color: rgb(13,13,13);">二、PR（Pull Request）方式提交(公司内代码审核) </span>Develop → Release**

****请在代码评审会议中确认 公司代码审核者****

------------------------------------------------------------------------

------------------------------------------------------------------------

**<span style="color: rgb(13,13,13);">PR 描述应该包括以下关键点：</span>**

<span style="color: rgb(13,13,13);">1 变更内容（What）</span>

- 详细描述 PR 主要做了什么改动。
- 提及涉及的代码模块或影响范围。

2 变更原因（Why）

- 为什么要进行这些改动？
- 解决了什么问题，或者带来了什么优化？

3 影响范围（Impact）

- 是否影响了已有的功能？
- 是否有兼容性问题？
- 是否需要额外的配置或数据库变更？

\

\

**例子**

------------------------------------------------------------------------

------------------------------------------------------------------------

**PR 标题 新增订单导出功能**

<span class="hljs-section">\### 变更内容（What）</span> 

      - 在 <span class="hljs-code">\`OrderService\`</span> 中新增 <span class="hljs-code">\`exportOrders()\`</span> 方法，支持导出订单数据为 Excel

<span class="hljs-bullet">      -</span> 在前端 <span class="hljs-code">\`OrderPage.vue\`</span> 页面新增导出按钮

<span class="hljs-bullet">      -</span> 增加单元测试，覆盖率达 95%

<span class="hljs-section">\### 变更原因（Why）</span>

<span class="hljs-bullet">     -</span> 业务需求：客户希望能够导出订单数据进行分析

<span class="hljs-bullet">     -</span> 之前只能手动复制粘贴，效率较低

<span class="hljs-section">\### 影响范围（Impact）</span>

<span class="hljs-bullet">    -</span> 影响 <span class="hljs-code">\`OrderService\`</span> 和 <span class="hljs-code">\`OrderPage.vue\`</span>

<span class="hljs-bullet">    -</span> 需要安装 <span class="hljs-code">\`xlsx\`</span> 依赖库

<span class="hljs-bullet">    -</span> 预计不会影响现有功能
