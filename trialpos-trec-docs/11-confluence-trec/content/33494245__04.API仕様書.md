# 04.API仕様書

API仕様書は、APIの設計や利用方法を詳細に記述した文書です。YAPIを活用することで、バックエンド側の詳細処理内容も記録し、APIのエンドポイントやリクエスト・レスポンスの仕様を明確にします。
