##   重要补充:   
取引の基底クラスのプロパティの中

public State CurrentState {get;set}  
 
public TranState TranState {get;}   

public TranState MainTranState{get;}  

**3つのステートプロパティ定義されています。**  
        
*  １） 値変更できるのは　　CurrentState   
*  ２）　CurrentState　に与える　値　の　クラス定義　は 
　　

**1. Stateの场合**  
         
    CurrentState = 与える値      
                  　　
    TranState = 変更なし     
               　　
    MainTranState = 変更なし                    　　

**2. TranStateの场合** 

  **TranStateの初期化 isMainState=True**  
       
    CurrentState = 与える値      
                  　　
    TranState = 与える値      
               　　
    MainTranState = 与える値                     　　
        　

  **TranStateの初期化 isMainState=False**  
    
    CurrentState = 与える値      
                  　　
    TranState = 与える値      
               　　
    MainTranState = 変更なし 
		
### 备注：    
1・定义状态的时候，要注意状态类型  
2・状态与画面的关联  
3・状态在XML（statewinpos.xml）配置控制command的执行可否
