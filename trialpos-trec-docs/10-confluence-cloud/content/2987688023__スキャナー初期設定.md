# スキャナー初期設定

いくつかのスキャナー種類があります

1.UPC-A、UPC-E、EAN-13、EAN-8の読み取り許可  
2.C/D送信する  
3.2 度読み防止時間 1.0sec  
4.スリープモード 1.5sec   
読取確認音長さ 120msec  
5.携帯モード常時  
6.QRコードを読ませる  
7.書籍 JAN2 段有効  
8.書籍 JAN2 段コード一括送信 有効  
9.Data Matrix 読取 無効  
PDF417 読取 無効  
10.UPC-A桁調整用”0”をつける  
11.UPC-E桁調整用”0”をつける  
12.スピーカ音量
