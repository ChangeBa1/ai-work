# 日中レビュー会議ルール

レビューのやり方

①議題：何の話なのか？日本側からの要望は何なのか？  
②レビューの目的：日本側に何を確認して欲しいのか？決めてほしいのか？  
③現状確認と影響：現状の処理の流れ・処理パターン・どこに影響するか・影響度合い  
④修正案：修正方法・修正ポイント・工数・影響・メリット・デメリット  
⑤結論：どの修正案がおすすめなのか？その理由
