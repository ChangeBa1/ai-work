# バーコード無し商品

以下２つのAPIを使って実現する。  
①でカテゴリIDを取得して、②でカテゴリ内のボタン情報を取得するという流れになります。

**①Hybrid Get NonBarcode Categories**   
　・バーコード無し商品ボタンのカテゴリ情報を取得するAPI

**②Hybrid Get NonBarcode Item**  
　・バーコード無し商品ボタンの情報を取得するAPI  
　・①で取得した「バーコード無し商品ボタンのカテゴリＩＤ」をリクエストパラメータにセットする必要がある  
　・ボタンの順番はレスポンスに現れるItems配列のインデックスの順番

ここにマニュアルがあります。  
<custom data-type="smartlink" data-id="id-0">https://sandbox-console.raicart.io/ja/admin/engineer/documentation/manju/api</custom> 

リンク先の内容：

**Hybrid Get NonBarcode Categories**

Details

* This is a public API and expecting Client-Id and Client-Secret on the request header.
* This API should call from a payment machine.
* This API also check the source IP address. Please, contact backend devs to whitelist your gateway ip addressees.
* To get your Client-Id and Client-Secret, please contact with backend devs.
* Please provide Content-Type: application/json as header and do not include like charset=utf8; in Content-Type header.
* This API will return a list of non barcode categories of the store if Client-Id and Client-Secret is valid.

**Hybrid Get NonBarcode Item**

Details

* This is a public API and expecting Client-Id and Client-Secret on the request header.
* This API should call from a payment machine.
* This API also check the source IP address. Please, contact backend devs to whitelist your gateway ip addressees.
* To get your Client-Id and Client-Secret, please contact with backend devs.
* Please provide Content-Type: application/json as header and do not include like charset=utf8; in Content-Type header.
* This API will return items list object if Client-Id and Client-Secret is valid.
* categoryId will be avaialble to the payment machine via **Hybrid Get NonBarcode Categories** API.
* Please check nonBarcodeCategories parameter on **Hybrid Get NonBarcode Categories** API
