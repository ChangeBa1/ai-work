# 26桁JANコード

### コード構成

商品コード(13桁) ＋ 消費期限(6桁) ＋ フラグ(1桁) ＋ 固定0／マーク(2桁)+固定0／値割引値(5桁) ＋ C/D

‌

消費期限：一般的に MMDDHHの構成です。

・フラグ==1 且つ マーク!=00 っ場合、 yyMMdd の意味です。

※YYYYMMDDへ転換したの年が19XXの場合、100年を加算する

‌

フラグ：

０：消費期限6桁読み取り（MMDDHH）  
１：消費期限4桁読み取り（MMDD）※HH読まない  
２：使用しない  
３：使用しない  
４：旧１の 新０パターン  
５：旧１の 新１パターン  
６：旧２の 新０パターン  
７：旧２の 新１パターン  
８：旧３の 新０パターン  
９：旧３の 新１パターン

※旧1：割引 　旧2：値引　　旧3：新価格

‌

MarkDown商品（20桁）：

13桁JAN   +   フラグ(1桁)    +   値割引新価格値(5桁)   +   ＋ C/D

フラグ：

1：割引 

2：値引

3：新価格
