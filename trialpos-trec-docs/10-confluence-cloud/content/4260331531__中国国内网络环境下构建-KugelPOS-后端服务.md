## 二、配置 DNS（修复国内服务器 DNS 失效问题）

```
# 删除 systemd-resolved 符号链接，创建真实 resolv.conf
rm /etc/resolv.conf
tee /etc/resolv.conf << 'EOF'
nameserver 114.114.114.114
nameserver 223.5.5.5
nameserver 8.8.8.8
EOF

# 配置 systemd-resolved 上游 DNS
mkdir -p /etc/systemd/resolved.conf.d
tee /etc/systemd/resolved.conf.d/dns.conf << 'EOF'
[Resolve]
DNS=114.114.114.114 223.5.5.5
FallbackDNS=8.8.8.8
EOF

systemctl restart systemd-resolved

# 验证
getent hosts baidu.com
getent hosts mirrors.tuna.tsinghua.edu.cn
```

## 三、配置 PyPI 国内镜像（pip / uv / pipenv）

### 3.1 pip 镜像配置

```
mkdir -p ~/.config/pip
cat > ~/.config/pip/pip.conf << 'EOF'
[global]
index-url = https://pypi.tuna.tsinghua.edu.cn/simple
trusted-host = pypi.tuna.tsinghua.edu.cn
EOF
```

### 3.2 uv 镜像配置（Hatch 构建时使用）

```
mkdir -p ~/.config/uv
cat > ~/.config/uv/uv.toml << 'EOF'
[global]
index-url = "https://pypi.tuna.tsinghua.edu.cn/simple"
EOF
```

### 3.3 环境变量（写入 \~/.bashrc 永久生效）

```
cat >> ~/.bashrc << 'EOF'

# PyPI 国内镜像配置
export UV_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple
export PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple
export PIP_TRUSTED_HOST=pypi.tuna.tsinghua.edu.cn
export PIPENV_PYPI_MIRROR=https://pypi.tuna.tsinghua.edu.cn/simple
EOF

source ~/.bashrc
```

## 五、安装 Docker（使用清华镜像）

### 5.1 添加 Docker 仓库（清华源）

```
# 获取 GPG key（从清华镜像）
curl -fsSL https://mirrors.tuna.tsinghua.edu.cn/docker-ce/linux/ubuntu/gpg \
  | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg

# 添加 Docker 仓库
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] \
  https://mirrors.tuna.tsinghua.edu.cn/docker-ce/linux/ubuntu \
  $(lsb_release -cs) stable" \
  | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

sudo apt update
```

### 5.2 安装 Docker

```
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

sudo systemctl start docker
sudo systemctl enable docker

docker --version
docker compose version
```

## 六、配置 Docker 国内镜像源

```
sudo tee /etc/docker/daemon.json << 'EOF'
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://dockerhub.icu",
    "https://docker.1panel.live"
  ],
  "dns": ["114.114.114.114", "223.5.5.5"]
}
EOF

sudo systemctl daemon-reload
sudo systemctl restart docker

# 验证
docker info | grep -A5 "Registry Mirrors"
docker pull python:3.12-slim
```

### 7.3 修复 Docker 内部 pip 镜像问题（不改代码）

> **根本原因分析**：
>
> * `pip install pipenv` ✅ 成功 → 系统 pip 读取了 `/etc/pip.conf`
> * `pipenv install --deploy --ignore-pipfile` ❌ 失败 → pipenv 从 Pipfile.lock 的 `sources` 字段读取 `https://pypi.org/simple`，**显式传递** `--index-url pypi.org` **给 pip**，覆盖所有 ENV 变量和 pip.conf
> 

**三种配置的覆盖层级对比：**

| 配置方式 | 作用层 | 被 `--index-url` 覆盖？ |
| --- | --- | --- |
| `PIP_INDEX_URL` 环境变量 | pip | ❌ 会被覆盖 |
| `/etc/pip.conf` | pip | ❌ 会被覆盖 |
| `PIPENV_PYPI_MIRROR` | **pipenv 内部** | ✅ 不会被覆盖 |

**正确解决方案（使用** `PIPENV_PYPI_MIRROR`**）：**

```
# 重建 builder 阶段基础镜像（使用 pipenv 专属镜像变量）
docker build -t python:3.12.11 - << 'EOF'
FROM python:3.12.11
ENV PIPENV_PYPI_MIRROR=https://pypi.tuna.tsinghua.edu.cn/simple
ENV PIP_TRUSTED_HOST=pypi.tuna.tsinghua.edu.cn
RUN echo "[global]" > /etc/pip.conf && \
    echo "index-url = https://pypi.tuna.tsinghua.edu.cn/simple" >> /etc/pip.conf && \
    echo "trusted-host = pypi.tuna.tsinghua.edu.cn" >> /etc/pip.conf
EOF

# 重建 runtime 阶段基础镜像
docker build -t python:3.12-slim - << 'EOF'
FROM python:3.12-slim
ENV PIPENV_PYPI_MIRROR=https://pypi.tuna.tsinghua.edu.cn/simple
ENV PIP_TRUSTED_HOST=pypi.tuna.tsinghua.edu.cn
RUN echo "[global]" > /etc/pip.conf && \
    echo "index-url = https://pypi.tuna.tsinghua.edu.cn/simple" >> /etc/pip.conf && \
    echo "trusted-host = pypi.tuna.tsinghua.edu.cn" >> /etc/pip.conf
EOF

# 重新构建（加 --no-cache 确保使用新基础镜像）
time ./build.sh --prod --no-cache account
```

> ⚠️ **关键**：`PIPENV_PYPI_MIRROR` 是 pipenv 专属环境变量，它会在 pipenv 内部直接替换 Pipfile.lock `sources` 里的 URL，**在调用 pip 之前**就完成替换，因此不受 pip 的 `--index-url` 命令行参数影响。

### 7.4 构建和运行生产镜像

```
time ./build.sh --prod
time ./start.sh --prod
```

## 九、故障排查

| 症状 | 原因 | 解决 |
| --- | --- | --- |
| `git: command not found` | git 未安装 | `apt-get install -y git` |
| `Connection reset by peer` (pip 宿主机) | PyPI 被封 | 配置 `~/.config/pip/pip.conf` 使用清华镜像 |
| `Connection reset by peer` (hatch/uv) | PyPI 被封，uv 不读 pip.conf | 设置 `UV_INDEX_URL` 环境变量 |
| Docker 构建内 `pip install` 失败 | 容器内不继承宿主机 pip 配置 | 重建本地基础镜像内置 pip 镜像（见 7.3） |
| Docker 镜像拉取失败 | Docker Hub 被封 | 配置 `/etc/docker/daemon.json` 镜像源 |
| DNS 无法解析 | systemd-resolved 配置异常 | 替换 `/etc/resolv.conf`，写入 114/223 DNS |
| `docker.mirrors.tuna.tsinghua.edu.cn` 解析失败 | 清华 Docker 镜像已停服 | 改用 `docker.m.daocloud.io` |
| `^[[200~` 出现在命令输入 | 终端 bracketed paste mode 冲突 | 逐行粘贴或用 `printf` 写入文件 |
