# ManjuとのAPI仕様

残高更新 [https://{0}/v1/user/hook/balance/update](#)

This push notification is for real time balance update of the user. For example, after adding some cah by the user from cash register (ATM) then `manju` will push this notification to all the devices (uuid) where this user currently logged in.

* Details

    * Response Details [Error Code](https://jsapi.apiary.io/previews/null/introduction/push-notification/balance-update-(app)#ResponseDetailsLink).
    * Channel to listen: `cart_channel_namespace:cart_<deviceUniqueId>`.
    * `type` is the notification type.
    * `userId` is the retailer user id.
    * `pointCard` is the point card data of the user.
    * `prepaidCard` is the prepaid card data of the user.
    

```json
{
    "data": {
        "type": "prepaidBalanceUpdate",
        "userId": "2960000000602",
        "pointCard":{
            "amount": 551,
            "cardId": "2960000000081",
            "lostPoint": 0,
            "lostPointAt": null,
            "salesPoint": 0,
            "salesPointDetail": null,
            "usePoint": 0,
            "courtesyLevel": 8
        },
        "prepaidCard": {
            "amount": 16732,
            "cardId": "8812960000000081",
            "paymentProviderTransactionId": "8129544650"
        }
    }
}
```
