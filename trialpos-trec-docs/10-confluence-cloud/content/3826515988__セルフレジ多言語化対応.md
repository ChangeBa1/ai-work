# セルフレジ多言語化対応

■対象範囲

セミセルフ会計機、フルセルフ

 

■仕様

・ベースはチャージ機の多言語対応と同じ。

・フルセルフではNeutral(初期画面)、セミセルフ会計機では支払選択画面に言語切替ボタンを配置する。

・切替処理は各画面のUpdateDisplayから呼んでいるSetMessageContent内に記載。SelfHeader等の共通モジュールはそのモジュールを使用している各画面から共通モジュールのSetMessageContentを呼ぶ。

・セルフレジ内のプリカチャージ画面も多言語対応済。

・切替えた言語設定は、そのトランザクション内のみで有効。支払い完了したりキャンセルした場合は日本語に戻る。中間トランや未了トランにも設定は残らない。

・現状チャージ機同様ボタン表示OFF機能は存在しない。

・バーコードなし商品画面のカテゴリの値はDBから取得しているので日本語のまま

‌

■新しい表示項目を追加するときの手順

1. MessageIdsにその項目のIdとIdの末尾\_EN_US, ZH_CNの3つを追加する。
2. Message.ja_JP.xml, Message.en_US.xml, Message.zh_CN.xmlに項目追加する。
3. 追加した項目が存在する画面のxaml.cs内のSetMessageContent内に該当MessageIdの処理を追加する。(なければUpdateDisplay等に追加。)
