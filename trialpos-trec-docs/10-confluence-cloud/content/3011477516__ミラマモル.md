# ミラマモル

### 1. カメラ映像ON

* リクエスト

| アドレス | cam_start |
| --- | --- |
| メソッド | GET |

* 引数

　　なし

* 処理  

    * 画面にカメラ映像を表示  
    
* レスポンス  

    * ステータス  
    

| HTTPステータス | 意味 |
| --- | --- |
| OK                 | カメラ映像が正常に表示 |
| INTERNAL_ERROR     | 内部処理エラー                                            |
| REQUEST_TIMEOUT    | タイムアウト                                              |

### 2. カメラ映像OFF 

* リクエスト  

| アドレス | cam_stop |
| --- | --- |
| メソッド   | GET      |

* 引数  

　　なし

* 処理  

    * カメラ映像を非表示
    
* レスポンス  

    * ステータス  
    

| HTTPステータス | 意味 |
| --- | --- |
| OK                 | カメラ映像が正常に表示終了 |
| INTERNAL_ERROR     | 内部処理エラー                                            |
| REQUEST_TIMEOUT    | タイムアウト                                              |
