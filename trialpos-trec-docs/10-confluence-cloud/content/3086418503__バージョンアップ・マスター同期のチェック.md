# バージョンアップ・マスター同期のチェック

### ■   テスト目的

‌    ・   ファイル正常にダウロードできる  
    ・   バージョンアップ時、解凍失敗したら、再実行できる  
    ・   マスタ同期時、解凍失敗したら、再実行できる

### ■   テストの前提/環境について

‌    ・   Azureに最新バージョンがある  
    ・   テスト実施前に、壊れたzipファイル準備  
    ・   SettingWinPOS.xmlにModuleVersion値は該当モジュールバージョン似合っているかどうか確認  
        <Setting Key="ModuleVersion" Value="2023102301" />

### ■   テストの着眼点

####    ■   テストの関係性を明確にするための分離    

‌       ・   POS起動時のLancher処理  
            VersionUp、及び、Master同期で共通  
            再試行時に、最新情報がある場合、ダウロードしたzipファイル削除して、再取得から行う

####    ■   テストの準備や実行に関してパターン化を作る整理

‌       ・   テスト準備パターン１：配信設定  
            a   配信設定無  
            b   VersionUp配信設定済み  
            c   Master同期配信設定済み  
            d   VersionUp、及び、Master同期配信設定済み

‌       ・   テスト準備パターン２：実行処理  
            A   成功  
            B   失敗
