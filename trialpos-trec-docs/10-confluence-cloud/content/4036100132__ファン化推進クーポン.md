# ファン化推進クーポン

### 目的・背景

・顧客を深いファンへと育成するには、商品への信頼に加え、行動を促す「きっかけ」が不可欠である。

・**”強烈なインパクトのあるクーポン”**は、顧客が家族向け商品や高価格帯商品、普段購入しないカテゴリへ挑戦する際の心理的障壁を取り除き、ファン化を効果的に促進する強力な動機付けとなる。

・本プロジェクトは、クーポンが**顧客のファン化を深耕させる効果的な手段**であることを証明し、実績につなげていくことが目的である。

※強烈なインパクトのあるクーポン：例えば商品全額分のポイントが付く（実質無料）など

### 要件

・”強烈なインパクトのクーポン”は、1回あたりのコストが大きいため、「利用回数や予算に上限」の設定を可能とする。

・利用回数やコストをコントロールするため、利用実績をリアルタイムでの把握を可能とする。

### 仕様

クーポンはTRIAL+のクーポン画面を利用して、クーポンを選択した会員が会員価格が適用されるものとする。

クーポン上限設定は以下の3階層で構成し、今回は下記の★の組み合わせのみ対象とする

第1階層（キャンペーン全体）

総利用回数　★

総割引額

第2階層（会員単位）

会員あたりの購入回数　★

会員あたりの累計割引額

第3階層（1取引）

1回の最大割引額

1回の割引適用個数　★
