# イベントコンバーター

イベントコンバーターは無いです。

取引タイプごと、コマンド変換があります。

StateEventWinPOS.xml

```
<?xml version="1.0" encoding="utf-8" ?>
<Root>
  <TranType Id="Lock">
    <Command Before="Common_SignInOut"
             After="Lock_SignIn" />
  </TranType>
</Root>
```

`Common_SignInOut`実行する時、取引タイプがLockの場合、`Lock_SignIn`へ変換して実行します。
