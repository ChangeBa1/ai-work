# ポイント計算について

‌

## 基本ポイント

基本ポイントの計算について

```none
ポイント対象金額 * 通常倍率 / ポイント基準額  (小数切り捨て)
```

・ポイント対象金額

　通常ポイント対象額と支払ポイント対象額を比較し、小さい方の金額

・通常倍率

　SettingMasterKeys.PointNormalRate

・ポイント基準額

　SettingMasterKeys.PointBaseAmount

## 特定倍率ポイント

特定倍率ポイントの計算について

```none
SUM(特定倍率ポイント対象金額 * (ポイント倍率 - 通常倍率)) / ポイント基準額  (小数切り捨て)
```

・特定倍率ポイント対象金額

　ポイント対象額より特定倍率ポイント対象額が大きい場合、倍率が大きい順にポイント対象額を割り当てる

## メディア倍率ポイント

メディア倍率ポイントの計算について

```none
SUM(支払対象金額 * (支払ポイント倍率 - 通常倍率)*　通常倍率 / ポイント基準額 (小数切り捨て))
```

ポイント対象額より支払額が大きい場合、倍率が大きい順に割り当てる

## 優待倍率ポイント

優待倍率ポイントの計算について

```none
基本ポイント * (優待倍率 - 通常倍率) (小数切り捨て)
```

## 個別電子クーポンポイント

個別電子クーポンポイントの計算について

```none
ポイントの場合：ポイント * 数量
倍率の場合：(採用される売単価-内税額) * 倍率 / ポイント基準額  (小数切り捨て) * 数量
```

・採用される売単価

　UnitPriceForPurchase

　変化売価＞特別売価＞通常売価の順に採用する

## RMクーポンポイント

RMクーポンポイントの計算について

```none
ポイントの場合：ポイント * 数量
倍率の場合：(採用される売単価-内税額) * 倍率 / ポイント基準額  (小数切り捨て) * 数量
```

## チャージポイント

チャージポイントの計算について

```none
ポイントタイプが（PointType=0）固定の場合：入金額／MinMoney * PointBase
ポイントタイプが（PointType=1）固定の場合：入金額 * (PointBase／100)　※入金額の〇%のポイント数を付与する
```

MinMoney(基準値 兼 最小金額)

PointBase(ポイント基準)

条件1：開始日開始時間:00 ≦ ポイント成立日時 ≦ 終了日終了時間:59

条件2：基準値 兼 最小金額 ≦ 入金額 ≦ 最大金額
