# 概要

‌    ランチャー是POS周边的工具，通过配置文件定义了一系列的步骤程序。 店铺内的POS端末每次启动时，则自启动ランチャー程序。

‌    ランチャー主要的功能是为了各个店铺的POS端末使用最新的数据（DB数据，最新版本，服务器时间等）。

‌
