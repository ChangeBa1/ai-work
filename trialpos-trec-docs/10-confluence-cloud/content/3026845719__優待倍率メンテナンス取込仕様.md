# 優待倍率メンテナンス取込仕様

企画No = "0000"が設定されていた場合、PointRankMasterへ

企画No = "0000"以外が設定されていた場合、PointRankScheduleMasterに変換を行う。

| ポイントランクマスタPointRankMaster | 優待倍率ベースメンテCBTTRPRD |
| --- | --- |
| No | Column Name | Description | Data Type | Precision  
Scale | Not  
Null | PK | 項番 | FFFF  
項目 | 削除 | 設定値 | 説明 |
| 1 | CompanyCode | 企業コード | nvarchar | 10 | Y | 1 |  |  | ○ | 対象の企業コード |  |
| 2 | StoreCode | 店舗コード | nvarchar | 10 | Y | 2 |  |  | ○ | 対象の店舗コード |  |
| 3 | Rank | 優待ステージ | int |  | Y | 3 |  |  | ○ | 1～10 |  |
| 4 | PointRankRate | ポイント倍率 | numeric | 3,1 | Y |  | 11\~19 | - |  | 優待倍率1～9 ÷ 10 | 0～999  
※ステージ１０は優待倍率９と同じ倍率で  
データを生成 |
