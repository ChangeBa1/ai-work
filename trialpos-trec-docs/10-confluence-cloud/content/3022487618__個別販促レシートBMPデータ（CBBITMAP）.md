# 個別販促レシートBMPデータ（CBBITMAP）

※画像ファイルを、ＺＩＰ形式で圧縮したファイル。

　画像ファイル名は、次の通り。

 　mmnnBITMAP.bmp

 　　mm：個別販促ﾚｼｰﾄNo（1～99）

 　　nn：02（２階調）、16（１６階調）

 　　圧縮ファイルのMAXサイズは730ＫＢ
