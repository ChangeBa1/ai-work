# 年齢確認

### 1. 年齢確認スタート

* リクエスト

| アドレス | ac_start |
| --- | --- |
| メソッド | GET |

* 引数

| **名前** | **説明** | **デフォルト** | **値域** |
| --- | --- | --- | --- |
| timeout | タイムアウトの時間を設定\[秒\] | 10 | \[1, 1000\] |

* 処理  

    * 画面にカメラ映像を表示  
    * 20歳以上フラグ（別リクエスト）が来た時点でレスポンスを返す
    
* レスポンス  

    * ステータス  
    

| HTTPステータス | 意味 |
| --- | --- |
| OK                 | 顔認証処理が正常終了                                         |
| INTERNAL_ERROR     | 内部処理エラー                                            |
| REQUEST_TIMEOUT    | タイムアウト                                              |
| FORBIDDEN          | ビジー  顔認証または年齢確認のリクエスト中に再度リクエストを送った場合に発生する。  |

* ボディ

コンテンツは、application/json

| 項目 | 意味 | 型 | OK | INTERNAL_ERROR | REQUEST_TIMEOUT | FORBIDDEN |
| --- | --- | --- | --- | --- | --- | --- |
| status        | ステータス           | int      | ✔️  | ✔️              | ✔️               | ✔️         |
| description   | ステータスの詳細       | string   | ✔️  | ✔️              | ✔️               | ✔️         |
| isOver20      | 20歳以上フラグ        | bool     | ✔️  | ‌                | ‌                 | ‌           |
| id            | カードID             | string   |  | ‌                | ‌                 | ‌           |
| name          | 顔認識した名前         | string   |  | ‌                | ‌                 | ‌           |
| confidence    | 信頼度 \[0, 1\]        | float    |  | ‌                | ‌                 | ‌           |

### 2. 年齢確認強制終了 

 年齢確認を終了する。

* リクエスト  

| アドレス | ac_stop |
| --- | --- |
| メソッド   | GET      |

* 引数  

| **名前** | **説明** | **デフォルト** | **値域** |
| --- | --- | --- | --- |
| by | 終了の理由 | 0 | 0:通常終了 1:アテンダントPCによる終了 2:スタッフによる終了 3:その他の要因による終了 |

* 処理  

    * 画面からカメラ映像を除去  
    * 顔認証処理のスタート（元仕様書記載ミス）  ⇒　年齢確認終了
    
* レスポンス  

    * ステータス  
    

| HTTPステータス | 意味 |
| --- | --- |
| OK              | 正常終了  |

* ボディ  

コンテンツは、application/json  

| 項目 | 意味 | 型 | OK |
| --- | --- | --- | --- |
| status        | ステータス           | int      | ✔️  |
| description   | ステータスの詳細       | string   | ✔️  |
| isOver20      | 20歳以上フラグ        | bool     |     |
| id            | カードID             | string   |     |
| name          | 顔認識した名前         | string   |     |
| confidence    | 信頼度 \[0, 1\]        | float    |     |
