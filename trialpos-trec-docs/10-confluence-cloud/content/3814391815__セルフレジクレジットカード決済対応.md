# セルフレジクレジットカード決済対応

■対象範囲

セミセルフ会計機、フルセルフ、ハイブリッド

‌

■仕様

・ベースはチャージ機のクレジット決済とする(CT6100_ModeSelf)

・支払選択画面にクレジットボタンを配置する。

・返品処理はサービスカウンターで行う(そもそもクレカ端末がセルフモードだと返品処理できない仕様)

‌

◇未了について

・タイムアウト(クレジット端末側で処理が完了したかどうかわからない状態)発生時には現在トランを未了トランとしてDBの未了テーブルに保存し、Attendant画面の未了一覧ボタンから確認できる。

・未了トランに対して、完了・呼出・削除処理を実行できる。

・完了処理はクレジット端末側で該当トランの処理が完了していた時に実行する。この場合はPaymentCode:オフラインクレジットで売り上げを建てる

・呼出処理はクレジット端末側で該当トランの処理が完了していた時かつもう一度支払をやりなおしたいときに実行する。未了トランから商品登録情報をロードし、支払選択画面からやり直せる。

・呼出処理はクレジット端末側で該当トランの処理が完了していた時かつ取引をやめるときに実行する。DBの該当未了トランが削除される。

・1件でも未了トランがDBに残っていると清算処理が実行できない(メッセージを出して止まる)

‌

◇クレカ端末に対するヘルスチェックについて

・ヘルスチェックはレジ袋枚数選択処理後、クレジットボタン押下後、クレジット端末再接続ボタン押下後に行われる。

・レジ袋枚数選択処理後のヘルスチェックが失敗した場合、支払選択画面のクレジットボタンは非活性状態になる。この状態からクレジットボタンを押せるようにするにはAttendant画面からクレジット端末再接続ボタンを押して接続成功する必要がある。

・クレジットボタン押下後のヘルスチェックが失敗した場合、元の状態に戻る。ヘルスチェックが成功する状態になったら再度ボタンを押下すれば処理が続行できる。(ex:まだクレカ端末で別処理を実行していて時間がたつと処理が終わり通信可能状態になる等)

‌

◇CT6100端末の特殊な動作

CT6100はネットワーク切断状態でも1回はPOSからの売上処理が実行できる。その後は端末側で一括処理を実行するまで次の売上処理ができない。これはチャージ機でも同様である。
