# エラー

INTERNAL_ERROR時には、statusに以下のエラー番号、descriptionに原因の詳細が付加されてレスポンスが送信される。

| **エラー番号** | **意味** |
| --- | --- |
| 10 | 認証装置内の例外処理で発生するエラー |
| 100 | カメラ異常 |
| 101 | カメラパーミッション不足 |
| 110 | 認識ライセンスエラー |
| 120 | 顔認証サーバー通信不可 |
| 121 | 顔認証サーバー内部エラー |
| 130 | 年齢認証サーバー通信不可 |
| 131 | リモート年齢サーバー内部エラー |
| 132 | オペレータ不在 |
