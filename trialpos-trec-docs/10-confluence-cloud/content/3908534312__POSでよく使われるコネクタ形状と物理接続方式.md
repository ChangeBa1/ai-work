# POSでよく使われるコネクタ形状と物理接続方式

## 1. USB 系（現行 POS の主力）

![](blob:https://media.staging.atl-paas.net/?type=external&localId=0974751d-a128-4160-b068-f3679091993e&id=&&collection=&height=675&occurrenceKey=null&width=1000&__contextId=null&__displayType=null&__external=false&__fileMimeType=null&__fileName=null&__fileSize=null&__mediaTraceId=null&url=https%3A%2F%2Fstatic4.arrow.com%2F-%2Fmedia%2Fimages%2Fresearch-and-events%2Farticles%2F1118%2Fusb-b_image-1.jpg%3Futm_source%3Dchatgpt.com)
![](blob:https://media.staging.atl-paas.net/?type=external&localId=22082ea2-22d1-4448-aa24-6e4040785b73&id=&&collection=&height=292&occurrenceKey=null&width=897&__contextId=null&__displayType=null&__external=false&__fileMimeType=null&__fileName=null&__fileSize=null&__mediaTraceId=null&url=https%3A%2F%2Fwww.usbmemorydirect.com%2Fblog%2Fwp-content%2Fuploads%2F2022%2F08%2FUSB-sizes.jpg%3Futm_source%3Dchatgpt.com)
### 概要

* **最も一般的**
* タッチパネル・周辺機器ともに使用
* 電源供給が可能

### 主なコネクタ

* USB Type-A（POS 本体側）
* USB Type-B（プリンタ・ディスプレイ側）
* USB-C（近年増加）

### 論理的な見え方

* USB HID（タッチパネルで最頻出）
* USB CDC（COMポートに見える）
* Vendor 独自ドライバ

### POS 実務上の注意

* **「USB = COM」ではない**
* タッチパネルはほぼ HID
* USB-C は「形状が同じでも中身が違う」

## 2. 映像系：HDMI / DisplayPort

（※タッチ信号は流れない）

![](blob:https://media.staging.atl-paas.net/?type=external&localId=899aa0d7-3ef7-4032-9d30-355da2b0ce7a&id=&&collection=&height=900&occurrenceKey=null&width=1200&__contextId=null&__displayType=null&__external=false&__fileMimeType=null&__fileName=null&__fileSize=null&__mediaTraceId=null&url=https%3A%2F%2Fupload.wikimedia.org%2Fwikipedia%2Fcommons%2Fthumb%2Fc%2Fc2%2FHDMI-Connector.jpg%2F1200px-HDMI-Connector.jpg%3Futm_source%3Dchatgpt.com)
![](blob:https://media.staging.atl-paas.net/?type=external&localId=fffd97f5-e7e0-4f51-ac66-da7948fb1d2c&id=&&collection=&height=1479&occurrenceKey=null&width=2444&__contextId=null&__displayType=null&__external=false&__fileMimeType=null&__fileName=null&__fileSize=null&__mediaTraceId=null&url=https%3A%2F%2Fupload.wikimedia.org%2Fwikipedia%2Fcommons%2Fa%2Fa6%2FDisplayport-cable.jpg%3Futm_source%3Dchatgpt.com)
### 概要

* ディスプレイ表示専用
* **タッチ入力は別配線**

### 主な用途

* タッチパネルディスプレイの映像入力
* POS 本体 → サブディスプレイ

### 実務上の重要ポイント

* **HDMI / DP 単体ではタッチ不可**
* 必ず USB（HID）とセット

```
POS本体
 ├─ HDMI / DP → 映像
 └─ USB → タッチ入力
```

## 4. RS-232C（D-sub 9pin / 25pin）

![](blob:https://media.staging.atl-paas.net/?type=external&localId=de8245db-30a5-4a0e-9d6d-fc57fd2c531a&id=&&collection=&height=2560&occurrenceKey=null&width=2560&__contextId=null&__displayType=null&__external=false&__fileMimeType=null&__fileName=null&__fileSize=null&__mediaTraceId=null&url=https%3A%2F%2Fm.media-amazon.com%2Fimages%2FI%2F71On32SuTlL.jpg%3Futm_source%3Dchatgpt.com)
![](blob:https://media.staging.atl-paas.net/?type=external&localId=502acaa8-a7cf-4e8c-8536-651a676a57a9&id=&&collection=&height=2560&occurrenceKey=null&width=2560&__contextId=null&__displayType=null&__external=false&__fileMimeType=null&__fileName=null&__fileSize=null&__mediaTraceId=null&url=https%3A%2F%2Fm.media-amazon.com%2Fimages%2FI%2F71zzod8cGrL.jpg%3Futm_source%3Dchatgpt.com)
### 概要

* **POS 業界の歴史そのもの**
* 自動釣銭機・秤・旧型タッチ制御

### 物理コネクタ

* DB9（最頻出）
* DB25（旧規格）

### 論理的な見え方

* Windows：COM1 / COM3 …
* Linux：/dev/ttySx

### 注意（極めて重要）

* **OPOS / POS for .NET とは無関係**
* COM に見えても USB-CDC の場合あり

## 10. まとめ（設計者向け）

| 分類 | 物理 | 主用途 | 設計上の位置づけ |

| USB         | Type-A/B/C  | タッチ   | 標準         |
| HDMI/DP     | 映像          | 表示    | USBと必ずセット  |
| RS-232C     | DB9         | 釣銭機   | レガシー       |
| Ethernet    | RJ-45       | IP機器  | 本命         |
| PoweredUSB  | 専用          | プリンタ  | 依存注意       |
| RJ-12       | ドロワ         | 開閉    | 通信ではない     |
