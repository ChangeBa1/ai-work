# イベント管理_DB管理

Source中定义的**事件（event）**，这些事件被用于以下集中场景：

1. 仅在Source内部使用，画面或设备事件等触发；（Azure用、POS用、4UFramework用）
2. 在数据库（DB）中管理，与键盘上的按键按下事件绑定；
3. 在数据库（DB）中管理，与画面上动态配置的按钮绑定（例如卖上页面的FunctionButton）；
4. 在Xml中管理的特定事件（例如：需要走BarcodeConvert的事件；MainMenu的按钮事件）

‌

事件在DB中进行管理的关联表如下

| **表名** | **说明** |
| --- | --- |
| EventConvertMaster | 场景2用，全店别数据，键盘KeyEvent转为POS用Event |
| EventGroupMaster | 场景2用，全店别数据，键盘KeyEvent转为POS用Event |
| EventGroupDetailMaster | 场景2用，全店别数据，键盘KeyEvent转为POS用Event |
| FunctionMenuMaster | 场景3用，店别数据， 如：売上FuntionButton、チャージ：languageButton |
| FunctionMenuButtonMaster | 场景3用，店别数据， 如：売上FuntionButton、チャージ：languageButton |
| PresetMenuMaster | 场景3用，店别数据，如：売上バーコードなし商品 |
| PresetMenuButtonMaster | 场景3用，店别数据，如：売上バーコードなし商品 |

**NO.3  \[dbo\].\[EventGroupDetailMaster\]全店别数据**

### 1）表字段说明

1. 企業コード(CompanyCode)：企业唯一标识
2. 店舗コード(StoreCode)：店铺唯一标识
3. イベントグループコード(EventGroupCode)：事件组编号，用于与事件转换主表(EventConvertMaster)，事件组主表(EventGroupMaster)关联
4. 入力データ順番(EventOrder)：事件执行顺序
5. イベントコード(EventCode)：事件唯一标识
6. 設定値区分(SettingDataType)：  
  １：EventGroupDetailMasterのSettingDataを使用  
  ２：入力値を使用（入力なくてもイベント処理をする）  
  ３：入力値を使用（入力ないときはイベント処理なし）  
  ４：PresetMenuButtonMasterのSettingDataを使用  
  ５：EventGroupDetailMasterのSettingDataを使用する  
      入力データが存在する場合は、『SettingData + ',' + 入力データ』を入力値とする  
  ６：PresetMenuButtonMasterのSettingDataを使用する  
      入力データが存在する場合は、『SettingData + ',' + 入力データ』を入力値とする
7. 設定値(SettingData)：事件指令执行参数
