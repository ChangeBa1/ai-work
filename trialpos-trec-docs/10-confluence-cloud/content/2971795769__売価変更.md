# 売価変更

## 売変・売価変更とは

商品につけれれた価格を変更すること

## 売変の種類

売変には値上げと値下げの売価変更作業が発生する  
売価にかかわるマスタ項目として

```
販売開始日　＝　売価変更指示が出る日
販売終了日　＝　この翌日に売価戻しがでる（特売に限る）
```

売価反映ロジックを元に商談システム・マスタメンテシステムの結果により店舗への売価反映が行われる

## 売変時間

* JOB実行は5:10～から実行され前日のマスタ更新を経てできた売価変更対象を元に指示書のデータを作成
* 6:00\~店舗プリンターによる自動印刷
