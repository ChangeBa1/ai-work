# RMのAPI仕様

* 共通なリクエスト定義

| パラメータ論理名 | パラメータ物理名 | 必須 | 型 | 最大桁 | 説明 |
| --- | --- | --- | --- | --- | --- |
| 企業コード | enterpriseCode | 〇 | string | 10 | 固定 |
| 店舗Id | storeId | 〇 | string | 10 | アプリの場合はマイストアの店舗番号 |
| 端末番号 | terminalId | 〇 | string | 10 | レジ番号、※アプリの場合はレジ番号がある？ |
| アクセスコード | accessCode | 〇 | string | 255 | 販促システムより発行したアクセスコード |

* 共通なレスポンス定義

| パラメータ論理名 | パラメータ物理名 | 必須 | 型 | 最大桁 | 説明 |
| --- | --- | --- | --- | --- | --- |
| 処理成功フラグ | isSuccess | 〇 | bool | － | 処理成功時:true、処理失敗時:false |
| エラーコード | errorCode | － | string | 4 | エラー時のエラーコード。成功時はnull |
| エラーメッセージ | errorMessage | － | string | 全角50桁 | エラー時のエラーメッセージ。成功時はnull |
| データ | data | － |  |  | 各機能を参照 |
