# ヘルスチェック

### ヘルスチェックを行う

* リクエスト

| アドレス | status |
| --- | --- |
| メソッド | GET |

* 引数

　　なし

* 処理

    * 端末のステータスを表示する
    
* レスポンス

    * ステータス
    

| HTTPステータス | 意味 |
| --- | --- |
| OK | 顔認証処理が正常終了 |

* ボディ

コンテンツは、application/json

| 項目 | 意味 | 型 | OK |
| --- | --- | --- | --- |
| status | ステータス | int | ✔️ |
| ipaddress | IPアドレス | string | ✔️ |
| devicestatus | 現在のステータス | string | ✔️ |
| ageMode | 年齢認証のみモードかどうか | bool | ✔️ |
| apikey | Skywayを使用する際のAPIKEY | string | ✔️ |
| version | アプリのバージョン名 | string | ✔️ |
| versionCode | アプリのバージョンコード | int | ✔️ |
| cameraStatus | 0:正常、エラーはエラーコード参照 | int | ✔️ |
| faceServerStatus | 0:正常、エラーはエラーコード参照 | int | ✔️ |
| ageServerStatus | 0:正常、エラーはエラーコード参照 | int | ✔️ |
| callButtonStatus | 0:呼び出しボタン無効、1:呼び出しボタン有効 | int | ✔️ |
