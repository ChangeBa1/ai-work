# 顔認証

### 1. 顔認証スタート

* リクエスト

| アドレス | fr_start |
| --- | --- |
| メソッド | GET |

* 引数

| **名前** | **説明** | **デフォルト** | **値域** |
| --- | --- | --- | --- |
| timeout | タイムアウトの時間を設定\[秒\] | 10 | \[1, 1000\] |

* 処理  

    * 画面にカメラ映像を表示  
    * 顔認証処理のスタート  
    
* レスポンス  

    * ステータス  
    

| HTTPステータス | 意味 |
| --- | --- |
| OK                 | 顔認証処理が正常終了                                         |
| INTERNAL_ERROR     | 内部処理エラー                                            |
| REQUEST_TIMEOUT    | タイムアウト                                              |
| FORBIDDEN          | ビジー 顔認証確認または年齢確認のリクエスト中に再度リクエストを送った場合に発生する。  |

* ボディ

コンテンツは、application/json

| 項目 | 意味 | 型 | OK | INTERNAL_ERROR | REQUEST_TIMEOUT | FORBIDDEN |
| --- | --- | --- | --- | --- | --- | --- |
| status        | ステータス           | int      | ✔️  | ✔️              | ✔️               | ✔️         |
| description   | ステータスの詳細       | string   | ✔️  | ✔️              | ✔️               | ✔️         |
| isOver20      | 20歳以上フラグ        | bool     | ✔️  | ‌                | ‌                 | ‌           |
| id            | カードID             | string   | ✔️  | ‌                | ‌                 | ‌           |
| name          | 顔認識した名前         | string   | ✔️  | ‌                | ‌                 | ‌           |
| confidence    | 信頼度 \[0, 1\]        | float    | ✔️  | ‌                | ‌                 | ‌           |

* リクエスト

| --- | --- |
| メソッド   | GET      |

* 引数

* 処理  

    * 画面からカメラ映像を除去  
    * 顔認証処理のスタート  
    
* レスポンス  

    * ステータス  
    

| HTTPステータス | 意味 |
| --- | --- |
| OK              | 正常終了  |

* ボディ  

コンテンツは、application/json  

| 項目 | 意味 | 型 | OK |
| --- | --- | --- | --- |
| status        | ステータス           | int      | ✔️  |
| description   | ステータスの詳細       | string   | ✔️  |
| isOver20      | 20歳以上フラグ        | bool     |     |
| id            | カードID             | string   |     |
| name          | 顔認識した名前         | string   |     |
| confidence    | 信頼度 \[0, 1\]        | float    |     |

### 3. 二段階認証

二段階認証検証のコマンドの送信。  
端末は認証コマンド待ち状態に移行して、認証成功しないとステータスが移行しない。  
強制終了する場合は、認証強制終了コマンドを実行する。

* リクエスト

    * アドレス: `fr_2fa`
    * メソッド: `POST`
    
* Headers

| Parameter | Type | Description |
| --- | --- | --- |
| Content-Type | String | application/json |

* Request Body

| Parameter | Type | Description |
| --- | --- | --- |
| pin | String | application/json |

* 処理

    * 認証中画面に遷移
    * 端末では2段階認証待ち状態に移行
    
* レスポンス

| HTTP | HTTPステータス | 意味 |
| --- | --- | --- |
| 200 | OK | 正常終了 |
| 400 | Bad Request | パラメータ不正 |

* ボディ  

コンテンツは、application/json  

ステータスに認証成功か認証失敗かの結果が入力される。

ステータスが0の場合のみ成功。それ以外の場合は失敗。

| 項目 | 意味 | 型 | OK |
| --- | --- | --- | --- |
| status        | ステータス           | int      | ✔️  |
| description   | ステータスの詳細       | string   | ✔️  |
| isOver20      | 20歳以上フラグ        | bool     |     |
| id            | カードID             | string   |     |
| name          | 顔認識した名前         | string   |     |
| confidence    | 信頼度 \[0, 1\]        | float    |     |
