# ai-work

个人 AI 工作记录项目，用于记录和归档我在日常工作与学习中使用 AI（如 Claude、ChatGPT 等）完成的各类任务，包括但不限于代码开发、问题排查、文档撰写、数据分析等。

## 项目目的

- 记录与 AI 协作完成的工作内容，方便日后回顾和复用
- 沉淀常用的提示词（Prompt）、工作流程和最佳实践
- 追踪任务进展与阶段性成果

## 目录结构

```
ai-work/
├── README.md              # 项目说明
└── tech-docs/             # 技术文档与学习笔记归档
    ├── 认知成长/            # 从初级开发到架构师的认知成长学习方案，含 AI 时代架构师能力变化笔记
    ├── WBS工作分解结构/      # WBS（工作分解结构）概念笔记及其与 Speckit 的关系
    ├── orca-中文使用教程/    # Orca 官方文档中文整理教程
    └── spec-kit-中文教程/   # GitHub Spec Kit 中文教程
```

本仓库为个人记录用途，内容持续更新中。
